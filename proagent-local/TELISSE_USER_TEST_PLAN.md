# ProAgent Local: Telisse User Test Plan

## Purpose

This is a focused user test for Telisse. The goal is not to prove the prototype is perfect. The goal is to learn what makes sense, what feels confusing, and what should be improved before broader testing.

## How to frame the test

Send Telisse this message:

> I am testing an early prototype called ProAgent Local. It lets a user create an AI agent, choose a role, give it a mission, generate workflows, run a safe simulation, save the setup, and export the package. This is not a finished product. Please test it like a normal user and tell me what is clear, what is confusing, and what you would change.

## What Telisse should test

Ask her to complete this flow:

1. Open the prototype.
2. Read the top section for no more than 30 seconds.
3. Explain what she thinks the product does.
4. Go to the Agent Builder.
5. Create an agent with a name and persona.
6. Write or edit the mission statement.
7. Review the AI Engine options.
8. Generate workflows.
9. Run one workflow simulation.
10. Save locally.
11. Export the package.
12. Explain what felt useful and what felt confusing.

## Key observations

Watch for these issues:

- Does she understand the purpose quickly?
- Does the term AI Engine make sense?
- Does she know which AI Engine option to choose?
- Does the Persona field make sense?
- Does the Mission field feel easy or intimidating?
- Do workflows feel useful or generic?
- Does Run Simulation feel valuable?
- Does Save Locally make sense?
- Does Export Package make sense?
- Does the product feel trustworthy?

## Feedback questions

Use these questions after the test:

1. In your own words, what does this product do?
2. What was the clearest part of the experience?
3. What was the most confusing part?
4. Did you understand what an AI Engine is?
5. Did the three AI Engine choices make sense?
   - Included AI Engine
   - Private Local AI
   - Bring Your Own AI Key
6. Which AI Engine would you choose and why?
7. Could you create an agent without help?
8. Was the Persona selection clear?
9. Was the Mission Statement easy to write?
10. Did the generated workflows feel useful?
11. Did the simulation output feel useful?
12. Did Save Locally make sense?
13. Did Export Package make sense?
14. Would you trust this product with personal or work tasks?
15. What would make it feel more trustworthy?
16. What would make it feel more valuable?
17. Would you pay for this? If yes, what price feels reasonable?
18. What should we improve first?

## What good feedback looks like

Good feedback is specific.

Better than:

> It was confusing.

Ask for:

> The AI Engine section confused me because I did not know why there were three choices.

Better than:

> I liked it.

Ask for:

> I liked the workflow generator because it showed me what the agent could actually do.

## Success criteria for this test

The test is successful if Telisse can answer these five questions clearly:

1. What does the product do?
2. Who is it for?
3. What problem does it solve?
4. What confused her?
5. What would make it worth paying for?

## Recommended next fixes after Telisse feedback

After the test, sort feedback into four categories:

1. Clarity problems
2. Trust problems
3. Usability problems
4. Value problems

Focus first on clarity and trust. If the user does not understand or trust the product, features will not matter.
